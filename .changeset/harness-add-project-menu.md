The Workspace "+" now opens an "Use Existing…" menu with two ways to add a project: **Open Folder** (browse and connect a local directory) and **Connect to GitHub** (paste a repo URL — the harness `git clone`s it with your machine's own git credentials, so public and private repos both work with no extra login — then adds it to your Workspace).
