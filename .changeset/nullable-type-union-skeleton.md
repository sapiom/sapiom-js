Fixed `exampleFromJsonSchema` (and its internal `skeletonFromJsonSchema`
helper) returning `null` for any field whose JSON Schema `type` is an array
containing `"null"` (e.g. `{ type: ["string", "null"] }`), instead of a
type-appropriate placeholder (`""`, `0`, `false`, etc.).

The `type` field can validly be an array of alternatives per the JSON Schema
spec, and some Zod versions (and non-Zod JSON Schema producers) represent a
nullable field this way. `exampleFromJsonSchema` is a public entry point for
schemas generated by whatever tooling the caller uses, so this shape now
normalizes to the schema's non-null type before generating the placeholder.
